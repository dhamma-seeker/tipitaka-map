# อานาปานสติสูตร (MN 118) เป็นโครงสร้างและสารบัญของพระไตรปิฎกได้หรือไม่
### รายงานวิจัย + เทียบเคียง 3 สูตร (SN 56.11 / DN 22 / MN 118) — วิเคราะห์จากตัวบทบาลีโรมันเท่านั้น

> **ข้อกำหนดวิธีวิจัย:** หลักฐานทุกชิ้นจากตัวบท**ภาษาบาลีโรมัน**โดยตรง (tripitaka-mcp local + online, ฐานข้อมูล SuttaCentral `bilara-data`) ไม่ได้พึ่งการแปลภาษาอังกฤษ/ภาษาอื่นในการวิเคราะห์ ตัวเลขทุกตัวสืบย้อนได้จาก `survey_corpus` (exhaustive `complete:true`)

## บทคัดย่อ (Abstract)

**คำตอบ: ได้ แต่เป็นรากชนิด "ลำดับวิธีปฏิบัติ" (practice cascade) ที่ครอบคลุม 3 ปิฎกอ่อนที่สุดในสามสูตร**

อานาปานสติสูตร ([MN 118](https://tripitaka-mcp.com/read/mn118)) ใช้เป็นราก/สารบัญได้ โดยมีโครงสร้างแกนคือ **"น้ำตก" (cascade)** ที่ตัวบาลีระบุชัด:

> *"อานาปานสติ ภิกฺขเว ภาวิตา พหุลีกตา **จตฺตาโร สติปฏฺฐาเน ปริปูเรติ**. จตฺตาโร สติปฏฺฐานา ภาวิตา พหุลีกตา **สตฺต โพชฺฌงฺเค ปริปูเรนฺติ**. สตฺต โพชฺฌงฺคา ภาวิตา พหุลีกตา **วิชฺชาวิมุตฺติํ ปริปูเรนฺติ**."* — [mn118:15.2–15.4](https://tripitaka-mcp.com/read/mn118#mn118:15.2)

นั่นคือ **อานาปานสติ 16 ขั้น → สติปัฏฐาน 4 → โพชฌงค์ 7 → วิชชาวิมุตติ** — เป็น "เส้นทางปฏิบัติที่สมบูรณ์ในตัวเอง"

**แต่ข้อค้นพบชี้ขาดในการเทียบ 3 สูตร:** ศัพท์ปลายทางของ MN 118 คือ **"วิชชาวิมุตติ" (vijjāvimutti)** ปรากฏ **เฉพาะสุตตันตปิฎกเท่านั้น** (54 ข้อความ; วินัย 0, อภิธรรม 0) และศัพท์แกน "อานาปาน" ก็แทบไม่อยู่ในวินัย/อภิธรรม (176/4/2) — ต่างจาก SN 56.11 ที่ศัพท์แกน "อริยสัจ" ปรากฏครบ 3 ปิฎก (344/23/34)

**จึงสรุปอันดับ "ความครอบคลุม 3 ปิฎก" (เชิงศัพท์):** **SN 56.11 > DN 22 > MN 118** — แต่ทั้งสามไม่ได้แย่งกัน หากแบ่งบทบาทตามธรรมชาติ:
- **SN 56.11 = โครง/สารบัญ** (WHAT: ธรรมะทั้งหมด = อริยสัจ 4)
- **DN 22 = หมวดธรรม** (WHO: นิวรณ์/ขันธ์/อายตนะ/โพชฌงค์/สัจจะ)
- **MN 118 = วิธีปฏิบัติ** (HOW: ลำดับการเจริญ 16 ขั้น → วิชชาวิมุตติ)

## 1. บทนำและสมมติฐาน

**คำถาม:** อานาปานสติสูตรใช้เป็นราก/สารบัญเชื่อมพระไตรปิฎกได้หรือไม่ และในสามสูตร (SN 56.11 / DN 22 / MN 118) ใครครอบคลุมดีที่สุด?

**สมมติฐาน H1 (ทดสอบแล้ว สนับสนุน):** ศัพท์แกนของ MN 118 (อานาปานสติ, สติปัฏฐาน, โพชฌงค์, อิทธิบาท, ปีติ, ปัสสัทธิ) กระจายถึงปิฎกทั้งสาม แต่อ่อนในวินัย และศัพท์ปลายทาง (วิชชาวิมุตติ) จำกัดอยู่ในสุตตันตะ

**สมมติฐาน H2 (ทดสอบแล้ว สนับสนุน):** MN 118 เชื่อมกับพระไตรปิฎกผ่าน "น้ำตก" (อานาปานสติ→สติปัฏฐาน→โพชฌงค์→วิชชาวิมุตติ) และสติปัฏฐาน = สัมมาสติ (องค์ที่ 7 ของมรรค) ซึ่งต่อเข้ากับไตรสิกขา → 3 ปิฎก

### 3.3 ข้อค้นพบชี้ขาด

**1) MN 118 มี "น้ำตก" ที่สมบูรณ์ในตัว** — อานาปานสติ 16 ขั้น (4 จตุรกะ) แต่ละจตุรกะเติมเต็มสติปัฏฐาน 1 หมวด ([mn118:24.5](https://tripitaka-mcp.com/read/mn118#mn118:24.5), [25.5](https://tripitaka-mcp.com/read/mn118#mn118:25.5), [26.5](https://tripitaka-mcp.com/read/mn118#mn118:26.5), [27.5](https://tripitaka-mcp.com/read/mn118#mn118:27.5)) แล้วสติปัฏฐาน 4 → โพชฌงค์ 7 → วิชชาวิมุตติ — เป็นเส้นทางเดียวจากลมหายใจถึงการรู้แจ้ง

**2) ศัพท์ปลายทาง "วิชชาวิมุตติ" จำกัดอยู่ในสุตตันตะ (54/0/0)** — นี่คือจุดต่างสำคัญ: SN 56.11 จบที่ "อริยสัจ" (ครบ 3 ปิฎก), DN 22 จบที่ "นิพพาน/อริยสัจ" (ครบ 3 ปิฎก), แต่ MN 118 จบที่ "วิชชาวิมุตติ" ซึ่งเป็นคำเฉพาะสุตตันตะ

**3) สะพานเชื่อมของ MN 118 = สัมมาสติ (องค์ที่ 7 ของมรรค)** — ตัวบาลีระบุ สติปัฏฐาน 4 = สัมมาสติ ([sn45.8:9.2](https://tripitaka-mcp.com/read/sn45.8#sn45.8:9.2)) และสติปัฏฐาน = สมาธินิมิตต์ ([mn44:12.3](https://tripitaka-mcp.com/read/mn44#mn44:12.3)) → ต่อเข้าไตรสิกขา → 3 ปิฎก ได้เส้นเดียวกับสองสูตรก่อน

## 5. อภิปราย (Discussion)

### 5.1 สามราก สามบทบาท (WHAT / WHO / HOW)

ผลเทียบเคียงชี้ว่ารากทั้งสามไม่ใช่คู่แข่ง หากแต่เป็น **3 ชั้นของแผนที่เดียวกัน** ที่ตัวบาลีเองเชื่อมไว้:

| ชั้น | พระสูตร | หน้าที่ | ศัพท์แกน (และขอบเขต) |
|---|---|---|---|
| **โครง (WHAT)** | SN 56.11 | ธรรมะทั้งหมด = อริยสัจ 4 (ปัญหา–เหตุ–ดับ–ทาง) | ariyasacca → ครบ 3 ปิฎก |
| **หมวด (WHO)** | DN 22 | แจกแจง "ธรรมที่ต้องดู" (นิวรณ์/ขันธ์/อายตนะ/โพชฌงค์/สัจจะ) | khandha/āyatana/dhātu → อภิธรรมลึก |
| **วิธี (HOW)** | MN 118 | ลำดับการเจริญ (16 ขั้น) → วิชชาวิมุตติ | ānāpāna → สติปัฏฐาน → โพชฌงค์ |

ความสัมพันธ์เชิงโครงสร้าง: **SN 56.11 ระบุ "สัมมาสติ" เป็นองค์ที่ 7 ของมรรค → DN 22 ขยาย "สัมมาสติ = สติปัฏฐาน 4" เป็นคู่มือ → MN 118 ให้ "เครื่องมือ" (ลมหายใจ) ที่เจริญสติปัฏฐานให้ถึงโพชฌงค์และวิชชาวิมุตติ** — ครบวงจรจาก "รู้ว่าต้องทำอะไร" ถึง "ทำอย่างไร"

### 5.2 ทำไม MN 118 ครอบคลุม 3 ปิฎกอ่อนสุด

อานาปานสติเป็น **กรรมฐาน (kammaṭṭhāna)** ที่เจาะจงไปที่กระบวนการภายใน (ลมหายใจ/เวทนา/จิต) — คำศัพท์ของมันจึงอยู่ใน **สุตตันตะ** (พระสูตร) เป็นหลัก ส่วนวินัย (วินิจฉัยข้อวัตร) และอภิธรรม (จำแนกธรรม) มี "จุดยืน" คนละแบบ: อภิธรรมสนใจ "หมวดธรรม" (ซึ่ง DN 22 แจกแจง) มากกว่า "กรรมฐาน" (ซึ่ง MN 118 สอน) จึงทำให้ MN 118 เชื่อมอภิธรรมผ่านสติปัฏฐาน/โพชฌงค์/ปีติ เท่านั้น และศัพท์ปลายทาง "วิชชาวิมุตติ" ก็ไม่ใช่วัตถุที่อภิธรรมหรือวินัยจำแนก

### 5.3 คำตอบสุดท้าย (ใครเป็นรากที่ดีที่สุด)

| เป้าหมาย | เลือก |
|---|---|
| สารบัญครอบคลุม **3 ปิฎกครบ** (โดยเฉพาะวินัย) | **SN 56.11** |
| ลงลึก**หมวดธรรม/อภิธรรม** | **DN 22** |
| **วิธีปฏิบัติ**ที่สมบูรณ์เป็นลำดับ (ถึงวิชชาวิมุตติ) | **MN 118** |
| แผนที่พระไตรปิฎกที่สมบูรณ์ที่สุด | **ใช้ 3 ชั้นรวมกัน**: SN 56.11 (โครง) → DN 22 (หมวด) → MN 118 (วิธี) |

**ข้อสรุปเชิงปริมาณ:** เมื่อวัด "ความครอบคลุม 3 ปิฎกเชิงศัพท์" ล้วน ๆ อันดับคือ **SN 56.11 > DN 22 > MN 118** — เพราะ SN 56.11 มีศัพท์แกน (อริยสัจ) ปรากฏในทั้ง 3 ปิฎก 3 รูปแบบวรรณกรรม (แสดง/เล่า/วิเคราะห์) ซึ่งเป็นคุณสมบัติเฉพาะตัวที่อีกสองสูตรไม่มี

---

## 6. ข้อจำกัดและการตรวจสอบตนเอง

1. **ศัพท์กว้างนับเกิน (over-match):** `pīti` ติด `pīta` (สีเหลือง/ดื่ม), `paṭinissagga` ในวินัย (80 ข้อความ) ส่วนมากเป็นคำใน **กรรมวาจา** (การสวดให้สละทิฏฐิ) ไม่ใช่ "ปฏินิสสัคคานุปัสสนา" ของจตุรกะ 4 → ตัวเลขวินัยของ paṭinissagga เป็นขอบเขตบนที่**ไม่ควรตีความว่าเชื่อมธรรมะโดยตรง**
2. **วิชชาวิมุตติ = 0 ในวินัย/อภิธรรม** เป็นข้อเท็จจริงเชิงศัพท์ แต่การ "บรรลุ" วิชชาวิมุตติเป็นผลของไตรสิกขาที่อภิธรรม/วินัยวิเคราะห์อยู่แล้ว → การไม่มีศัพท์ไม่ได้แปลว่าไม่มีความสัมพันธ์เชิงมโนทัศน์
3. **ไม่ได้นับระดับนิกาย** แบบ exhaustive (ทำเฉพาะอริยสัจในงาน SN 56.11)
4. ยังไม่ได้เทียบรากอื่น เช่น มหาจัตตารีสกสูตร (MN 117), สามัญญผลสูตร (DN 2) — งานต่อยอด

## 7. สรุป

**อานาปานสติสูตรใช้เป็นราก/สารบัญได้** โดยเป็นรากชนิด **"ลำดับวิธีปฏิบัติ"** ที่มี "น้ำตก" (อานาปานสติ→สติปัฏฐาน→โพชฌงค์→วิชชาวิมุตติ) สมบูรณ์ในตัว แต่**ครอบคลุม 3 ปิฎกอ่อนที่สุดในสามสูตร** (ศัพท์แกน "อานาปาน" เกือบเฉพาะสุตตันตะ และศัพท์ปลายทาง "วิชชาวิมุตติ" อยู่ในสุตตันตะเท่านั้น)

**แผนที่พระไตรปิฎกที่สมบูรณ์ที่สุด = 3 ชั้นรวมกัน:**
1. **SN 56.11** — โครง/สารบัญ (WHAT: อริยสัจ 4 ครอบคลุม 3 ปิฎก)
2. **DN 22** — หมวดธรรม (WHO: นิวรณ์/ขันธ์/อายตนะ/โพชฌงค์ → อภิธรรมลึก)
3. **MN 118** — วิธีปฏิบัติ (HOW: อานาปานสติ 16 ขั้น → วิชชาวิมุตติ)
