# มหาปรินิพพานสูตร (DN 16) เป็น root ชนิด "เกณฑ์วินิจฉัยความเป็นพุทธวจนะ + บทสรุปพระธรรม" ได้หรือไม่
### รายงานวิจัยเชิงลึก — วิเคราะห์จากตัวบทบาลีโรมันเท่านั้น (tripitaka-mcp local + online)

> **ข้อกำหนดวิธีวิจัย:** หลักฐานทุกชิ้นจากตัวบท**ภาษาบาลีโรมัน**โดยตรง (SuttaCentral `bilara-data` CC0) ไม่ใช้การแปลภาษาอังกฤษ/ไทยในการวิเคราะห์ ตัวเลขจาก `survey_corpus` (exhaustive `complete:true`) ตัวบท DN 16 ยาว (1664 ข้อความ) จึง fetch เฉพาะส่วนสำคัญ (จตุมหาปเทส / โพธิปักขิยธรรม / ปัจฉิมวาจา) ไม่ fetch เต็ม

## บทคัดย่อ (Abstract)

**คำตอบ: ได้ — มหาปรินิพพานสูตร ([DN 16](https://tripitaka-mcp.com/read/dn16)) เป็น root ชนิด "เชิงอำนาจ (authority) + บทสรุปพระธรรม"** ซึ่งต่างจาก SN 56.11 ที่เป็น "root เชิงเนื้อหา (what)"

DN 16 ทำหน้าที่สองอย่างที่ไม่มีพระสูตรอื่นทำครบ:

1. **เป็น "เกณฑ์วินิจฉัยความเป็นพุทธวจนะ" (จตุมหาปเทส):** ศัพท์ **"มหาปเทส" ปรากฏเพียง 13 ข้อความ (3 พระสูตร)** = เกือบเฉพาะ DN 16 และหลักเกณฑ์คือ *"สุตฺเต โอสาเรตพฺพานิ วินเย สนฺทสฺเสตพฺพานิ"* (เทียบกับ**สูตรและวินัย**) [dn16:4.8.5](https://tripitaka-mcp.com/read/dn16#dn16:4.8.5) — นี่คือ "root เชิงอำนาจ" ที่ตัวพระไตรปิฎกใช้**ตัดสินว่าข้อความใดเป็นพุทธวจนะ**
2. **เป็น "บทสรุปพระธรรม" (โพธิปักขิยธรรม 37):** DN 16 บรรจุ *"สติปัฏฐาน 4, สัมมัปปธาน 4, อิทธิบาท 4, อินทรีย์ 5, พละ 5, โพชฌงค์ 7, อริยอัฏฐังคิกมรรค"* [dn16:3.50.5](https://tripitaka-mcp.com/read/dn16#dn16:3.50.5) — ซึ่งคือ**กรอบรวมที่บรรจุ root ทั้งหมดที่วิจัยแล้ว** (มรรค 8 = SN56.11/MN117, สติปัฏฐาน = DN22, โพชฌงค์ = MN118) และปัจฉิมวาจา *"ธมฺโม จ วินโย จ … โส โว มมจฺจเยน สตฺถา"* (ธัมมวินัยคือศาสดา) [dn16:6.1.5](https://tripitaka-mcp.com/read/dn16#dn16:6.1.5)

## 1. บทนำและสมมติฐาน

**คำถาม:** DN 16 ใช้เป็น root ได้หรือไม่ และเป็น root ชนิดใด (เกณฑ์วินิจฉัยพุทธวจนะ = "root เชิงอำนาจ" ต่างจาก SN 56.11 "root เชิงเนื้อหา" อย่างไร)?

**สมมติฐาน H1 (ทดสอบแล้ว สนับสนุน):** DN 16 เป็น "root เชิงอำนาจ" — จตุมหาปเทส (เกือบเฉพาะ DN 16 = 13 ข้อความ) เป็นหลักฐานว่าพระสูตรนี้ประทาน**เกณฑ์ตัดสินความเป็นพุทธวจนะ** (เทียบกับสูตร+วินัย)

**สมมติฐาน H2 (ทดสอบแล้ว สนับสนุน):** DN 16 บรรจุโพธิปักขิยธรรม 37 = **กรอบรวมของ root ทั้งหมด** (satipaṭṭhāna/bojjhaṅga/magga อยู่ใน 37 นี้)

## 4. อภิปราย (Discussion)

### 4.1 DN 16 = "root เชิงอำนาจ" (authority) ต่างจาก SN 56.11 = "root เชิงเนื้อหา" (content)

| | SN 56.11 (root เชิงเนื้อหา) | DN 16 (root เชิงอำนาจ) |
|---|---|---|
| ตอบคำถาม | "ธรรมะ**คืออะไร**" (อริยสัจ 4) | "ข้อความใด**เป็นธรรมะ**" (จตุมหาปเทส) |
| ลายเซ็น | tiparivaṭṭa (ติปริวัฏฏ์) | mahāpadesa (มหาปเทส) |
| กลไก | นิยามเนื้อหา 4 หมวด | เกณฑ์เทียบกับ**สูตร+วินัย** |
| บทสรุป | อริยสัจ 4 = ธรรมะทั้งหมด | ธัมมวินัย = ศาสดา + อัปปมาทะ |

**ทั้งสองเสริมกัน:** SN 56.11 บอก "ธรรมะคืออริยสัจ 4"; DN 16 บอก "จะรู้ว่าอะไรเป็นธรรมะ (พุทธวจนะ) ให้เทียบกับสูตร+วินัย" — root เชิงเนื้อหา + root เชิงอำนาจ = แผนที่ครบ

### 4.2 หลักฐานว่ามหาปเทส = "เกณฑ์ตัดสินความเป็นพุทธวจนะ"

- ศัพท์ "มหาปเทส" ปรากฏ **เพียง 13 ข้อความ (3 พระสูตร)** = เกือบเฉพาะ DN 16 (และ [AN 4.180](https://tripitaka-mcp.com/read/an4.180) มหาปเทสสูตร) — เป็น "ลายเซ็น" ที่ไม่ซ้ำที่อื่น
- หลักเกณฑ์คือ **"สุตฺเต โอสาเรตพฺพานิ วินเย สนฺทสฺเสตพฺพานิ"** (เทียบกับสูตรและวินัย) [dn16:4.8.5](https://tripitaka-mcp.com/read/dn16#dn16:4.8.5) — นี่คือวิธีที่พระไตรปิฎก**กำหนดขอบเขตตัวเอง**
- ยืนยันด้วยปัจฉิมวาจา "ธมฺโม จ วินโย จ … โส โว มมจฺจเยน สตฺถา" [dn16:6.1.5](https://tripitaka-mcp.com/read/dn16#dn16:6.1.5)

### 4.3 DN 16 บรรจุโพธิปักขิยธรรม 37 = กรอบรวมของ root ทั้งหมด

โพธิปักขิยธรรม 37 [dn16:3.50.5](https://tripitaka-mcp.com/read/dn16#dn16:3.50.5) บรรจุ:
- **อริยอัฏฐังคิกมรรค (8)** = root ของ SN 56.11 + MN 117
- **สติปัฏฐาน 4** = root ของ DN 22
- **โพชฌงค์ 7** = root ของ MN 118
- **สัมมัปปธาน/อิทธิบาท/อินทรีย์/พละ** = root ย่อยเพิ่มเติม

→ DN 16 คือ "**root ของ root ทั้งหมด**" — เป็นกรอบ meta ที่รวมทุกพระสูตรหลักไว้ใน 37 ธรรมเดียว

## 5. ข้อจำกัดและการตรวจสอบตนเอง

1. **compound "aparihāniyadhamma" = 0** ในตัวบท (survey แบบ stem ไม่พบ) — แต่**มโนทัศน์** "อปริหานิยธรรม 7" มีจริงใน DN 16 §2–3 ในรูป **"อปริหานิยา ธมฺมา"** (แยกคำ, 28 ข้อความ, [dn16:1.5.4](https://tripitaka-mcp.com/read/dn16#dn16:1.5.4)) — ชื่อ compound เป็นชื่อ**หัวข้อหมวด** (Rāja/Bhikkhu-aparihāniyadhamma) ไม่ใช่คำในตัวบท
2. **ไม่ได้ fetch ตัวบท DN 16 เต็ม** (ตามข้อกำหนด) — วิเคราะห์จาก 3 ส่วนสำคัญ + outline (40 หมวด) เท่านั้น; หมวดอื่น (เช่น อัฏฐาภิภายตน, สังคีติย่อย) ไม่ได้แจกแจงรายละเอียด
3. **ศัพท์กว้าง (sīla/paññā) เป็นขอบเขตบน** (over-match: silā=หิน, paññatti=บัญญัติ)
4. งานนี้พิสูจน์ DN 16 เป็น root เชิงอำนาจ + บทสรุป แต่**ไม่ได้**เปรียบเทียบ "ความสำคัญ" เชิงปริมาณกับ root อื่นอย่างสมบูรณ์ (เป็นงานต่อยอด)

## 6. สรุป

**มหาปรินิพพานสูตรใช้เป็น root ได้** และเป็น root ชนิด **"เกณฑ์วินิจฉัยความเป็นพุทธวจนะ (จตุมหาปเทส) + บทสรุปพระธรรม (โพธิปักขิยธรรม 37)"** — หลักฐาน: (1) "มหาปเทส" ปรากฏ 13 ข้อความเกือบเฉพาะ DN 16 และเกณฑ์คือเทียบกับ**สูตร+วินัย** [dn16:4.8.5](https://tripitaka-mcp.com/read/dn16#dn16:4.8.5); (2) โพธิปักขิยธรรม 37 [dn16:3.50.5](https://tripitaka-mcp.com/read/dn16#dn16:3.50.5) = กรอบรวมของ root ทั้งหมด; (3) ปัจฉิมวาจา "ธมฺโม จ วินโย จ … สตฺถา" [dn16:6.1.5](https://tripitaka-mcp.com/read/dn16#dn16:6.1.5)
