# รายงานตรวจสอบความครอบคลุม (Coverage Audit) — แผนที่พระธรรมครอบคลุมพระไตรปิฎกแค่ไหน

> วิธี: union รายชื่อพระสูตรทั้งหมดที่ 34 ศัพท์ (ที่มี sutta-coverage) ชี้ไป เทียบกับจำนวน "section" จริงในแต่ละนิกาย/ปิฎก (จาก tripitaka-mcp `list_structure`)

---

## 1. ผลลัพธ์รวม

| ตัวชี้วัด | จำนวน |
|---|---|
| **พระสูตร/คัมภีร์ที่ถูก index ชี้ถึง (distinct)** | **1,558** |
| จำนวน section ทั้งพระไตรปิฎก (จริง) | **7,321** |
| **ความครอบคลุมรวม** | **21.3%** |

**คำตอบ: ยังไม่ครอบคลุมทั้งพระไตรปิฎก** — ปัจจุบันแผนที่ครอบคลุม ~21% (เน้นที่ "แกนกลาง" = 10 root + สะพานเชื่อม) ไม่ใช่ทั้งหมด

## 2. ครอบคลุมรายนิกาย/ปิฎก

| นิกาย/ปิฎก | ถูก index ชี้ถึง | จำนวนจริง | % ครอบคลุม |
|---|---:|---:|---:|
| **ทีฆนิกาย (DN)** | 25 | 37 | **67.6%** ✅ |
| **มัชฌิมนิกาย (MN)** | 88 | 155 | **56.8%** ✅ |
| สังยุตตนิกาย (SN) | 464 | 1,829 | 25.4% |
| อังคุตตรนิกาย (AN) | 361 | 1,419 | 25.4% |
| อภิธรรมปิฎก | 211 | 1,108 | 19.0% |
| ขุททกนิกาย (KN) | 387 | 2,351 | 16.5% |
| **วินัยปิฎก** | 22 | 422 | **5.2%** ⚠️ |

## 3. ทำไมเป็นเช่นนี้ (วิเคราะห์สาเหตุ)

1. **DN/MN ครอบคลุมสูง** เพราะ 10 root เกือบทั้งหมดอยู่ใน DN (5 สูตร) และ MN (4 สูตร) → ศัพท์แกนชี้กลับไปที่นิกายตัวเองมากที่สุด
2. **วินัยต่ำสุด (5.2%)** เพราะ (ก) เรา index ด้วยศัพท์ "ธรรมะ" (อริยสัจ/มรรค/สติปัฏฐาน) ซึ่งวินัยแทบไม่ใช้; (ข) คำศัพท์ของวินัยคือ **สิกขาบท/ปาติโมกข์/วิภังค์/กรรมวาจา** ซึ่งยังไม่ถูกนำมาเป็นศัพท์ index
3. **SN/AN/KN กลาง ๆ (~17–25%)** เพราะสองนิกายนี้ใหญ่ (1,800+ / 1,400+ / 2,300+ section) และมีหัวข้อเฉพาะ (เช่น SN แยกเป็น 56 สังยุตต์, KN รวมชาดก/อปทาน/คาถา) ที่ต้องใช้ศัพท์เฉพาะของแต่ละหมวด

## 4. จะทำให้ "ครบ" ได้อย่างไร (ข้อเสนอ)

| ลำดับ | การขยาย | คาดว่าจะเพิ่ม |
|---|---|---|
| 1 | เพิ่มศัพท์ของ**วินัย** (สิกขาบท, ปาติโมกข์, กรรมวาจา, ปาราชิก, สังฆาทิเสส…) | วินัย 5% → สูงขึ้นมาก |
| 2 | เพิ่มศัพท์ของ**ขุททกนิกาย** (ชาดก, อปทาน, คาถาธรรมบท, วิมาน/เปตวัตถุ…) | KN 16% → สูงขึ้น |
| 3 | เพิ่มศัพท์เฉพาะของ SN/AN แต่ละสังยุตต์/วรรค | SN/AN 25% → สูงขึ้น |
| 4 | ดึง **segment_id ครบ** (ไม่ใช่แค่ sutta_id) สำหรับศัพท์หลัก | ความละเอียดระดับท่อน |

**หลักการ:** "ศัพท์ index" ต้องเป็นศัพท์ที่ **ปรากฏบ่อยพอที่จะเป็นกุญแจ** แต่ไม่กว้างเกิน (เช่น "ปาติโมกข์" = กุญแจวินัยที่ดี, "ศีล" = กว้างเกิน)
