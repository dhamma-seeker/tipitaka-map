# Root เพิ่มเติม: พระสูตรที่ตัวพระไตรปิฎกใช้เป็น "สารบัญ" ของตนเอง
### รายงาน — ระบุและวิจัย "root" นอกเหนือจาก 5 สูตรที่ทำแล้ว วิเคราะห์จากตัวบทบาลีโรมันเท่านั้น

> **หลักฐาน:** ตัวบทภาษาบาลีโรมันเท่านั้น (tripitaka-mcp local + online, SuttaCentral `bilara-data` CC0) ตัวเลขจาก `survey_corpus` (exhaustive `complete:true`)

## 1. ข้อค้นพบหลัก: ตัวพระไตรปิฎกมี "root โดยธรรมชาติ" อยู่แล้ว 3 ชนิด

นอกจาก 5 สูตรที่วิจัยแล้ว (SN 56.11 / DN 2 / MN 117 / DN 22 / MN 118) พบว่ามีพระสูตรอีกกลุ่มที่ทำหน้าที่เป็น **"ราก/สารบัญโดยธรรมชาติ"** ที่ตัวคัมภีร์สร้างไว้เอง:

| ชนิดของ root | พระสูตร | กลไก | หลักฐาน |
|---|---|---|---|
| **สารบัญเชิงตัวเลข (mātikā)** | [DN 33](https://tripitaka-mcp.com/read/dn33) สังคีติสูตร + [DN 34](https://tripitaka-mcp.com/read/dn34) ทสุตตรสูตร | จัดหมวดธรรมตามจำนวน 1–10 (เอกกะ/ทุกะ/ติกะ…ทสกะ) — **คือ "มาติกา" ของพระไตรปิฎก** | มาติกา 98 ข้อความ ครบ 3 ปิฎก |
| **หลักวินิจฉัยความเป็นพุทธวจนะ (mahāpadesa)** | [DN 16](https://tripitaka-mcp.com/read/dn16) มหาปรินิพพานสูตร | จตุมหาปเทส 4 = เกณฑ์ตัดสินว่าข้อความใดเป็นพุทธวจนะ | มหาปเทส 13 ข้อความ (เกือบเฉพาะ DN 16) |
| **หลักสูตรกรรมฐาน (meditation curriculum)** | [MN 62](https://tripitaka-mcp.com/read/mn62) ราหุโลวาทสูตร + [MN 9](https://tripitaka-mcp.com/read/mn9) สัมมาทิฏฐิสูตร | ชุดกรรมฐานครบ (ธาตุ 4 → อานาปาน → พรหมวิหาร → อสุภ → อนิจฉสัญญา) | — |

## 2. สารบัญเชิงตัวเลข (mātikā): DN 33 + DN 34 = "สารบัญที่คัมภีร์สร้างเอง"

**นี่คือข้อค้นพบสำคัญที่สุดของรอบนี้** — สังคีติสูตร ([DN 33](https://tripitaka-mcp.com/read/dn33)) และทสุตตรสูตร ([DN 34](https://tripitaka-mcp.com/read/dn34)) **จัดหมวดธรรมตามจำนวนตั้งแต่ 1 ถึง 10** โดยตัวพระสูตรเอง:

```
DN 33 (1167 ข้อความ): เอกกะ(1) → ทุกะ(2) → ติกะ(3) → จตุกกะ(4) → ปัญจกะ(5)
                      → ฉักกะ(6) → สัตตกะ(7) → อัฏฐกะ(8) → นวกะ(9) → ทสกะ(10)

DN 34 (894 ข้อความ):  เอโก ธมฺโม → เทฺว ธมฺมา → ตโย ธมฺมา → … → ทส ธมฺมา
                      (แต่ละจำนวนมี 10 ข้อ = "ทสุตตระ" = "ถึงสิบ")
```

**หลักฐานเชิงปริมาณ:** ศัพท์ **"มาติกา" (mātikā)** ปรากฏ **ครบทั้ง 3 ปิฎก** — วินัย 46, สุตตันตะ 30, อภิธรรม 22 (รวม 98 ข้อความ/50 พระสูตร) และ DN 16 (มหาปรินิพพาน) เองก็กล่าวถึงพระภิกษุผู้ทรง **"มาติกาธร"** (ผู้ทรงแม่บท) ในหมวดมหาปเทส ([dn16:4.10.2](https://tripitaka-mcp.com/read/dn16#dn16:4.10.2))

→ **ความหมาย:** การจัด "ตามจำนวน 1–10" (ซึ่งเป็นโครงของอังคุตตรนิกาย และเป็นต้นแบบ "มาติกา" ของอภิธรรมธัมมสังคณี) **มีอยู่ในตัวพระสูตรเอง** — นี่คือ "สารบัญ" ที่พระไตรปิฎกสร้างไว้ให้ ไม่ใช่การตีความของเรา

## 3. หลักวินิจฉัยความเป็นพุทธวจนะ: DN 16 (จตุมหาปเทส)

มหาปรินิพพานสูตร ([DN 16](https://tripitaka-mcp.com/read/dn16)) — พระสูตรยาวที่สุด (1664 ข้อความ, 40 หมวด) มีหมวด **"จตุมหาปเทส" (4 มหาปเทส)** ซึ่งเป็น **เกณฑ์ที่พระพุทธเจ้าประทานไว้ให้ตัดสินว่าข้อความใดนับเป็น "พุทธวจนะ"** — นี่คือ "root เชิงอำนาจ" (authority) ของพระไตรปิฎกทั้งปวง:

> *"Idaṁ, bhikkhave, paṭhamaṁ mahāpadesaṁ dhāreyyātha"* — [dn16:4.8.13](https://tripitaka-mcp.com/read/dn16#dn16:4.8.13)

ศัพท์ **"มหาปเทส" ปรากฏเพียง 13 ข้อความ (3 พระสูตร)** = เกือบเฉพาะ DN 16 (และ AN 4.180 มหาปเทสสูตร) — เป็น "ลายเซ็น" เฉพาะตัว

นอกจากนี้ DN 16 ยังบรรจุ **โพธิปักขิยธรรม 37** ([dn16:3.50.5](https://tripitaka-mcp.com/read/dn16#dn16:3.50.5) — กรอบรวมของ 5 สูตรที่ทำแล้ว), **อริยสัจกถา** (หมวด 8), และ **ปัจฉิมวาจา "อปฺปมาเทน สมฺปาเทถ"** (อัปปมาทะ 187 ข้อความ)

## 4. หลักสูตรกรรมฐาน: MN 62 (ราหุโลวาท) + MN 9 (สัมมาทิฏฐิ)

- **[MN 62](https://tripitaka-mcp.com/read/mn62)** (มหาราหุโลวาทสูตร): ชุดกรรมฐานครบวงจร — ธาตุ 4 → อานาปานสติ → พรหมวิหาร 4 → อสุภสัญญา → อนิจจสัญญา (122 ข้อความ) — เป็น "หลักสูตร" ฉบับย่อที่ครอบคลุมกรรมฐานหลักทั้งหมด
- **[MN 9](https://tripitaka-mcp.com/read/mn9)** (สัมมาทิฏฐิสูตร): นิยาม "สัมมาทิฏฐิ" = ความรู้ใน อกุศล/กุศล → อาหาร 4 → อริยสัจ 4 → ปฏิจจสมุปบาท 12 → อาสวะ 3 — เป็น "แผนที่ของสัมมาทิฏฐิ" (234 ข้อความ, 72 หมวดย่อย)

*(ศัพท์ "พรหมวิหาร" (brahmavihāra) ปรากฏเพียง 4 ข้อความ — เป็นศัพท์หายาก แม้มโนทัศน์ เมตตา/กรุณา จะกว้างขวาง)*

## 5. ตารางรวม root ทั้งหมด (9 root, จำแนกตามชนิด)

| ชนิด | root | แก่น |
|---|---|---|
| **เชิงหลักการ (WHAT)** | SN 56.11 | อริยสัจ 4 = ธรรมะทั้งหมด |
| **เชิงลำดับ (PATH)** | DN 2 | ไตรสิกขา = 3 ปิฎกเป็น 3 ขั้น |
| **เชิงสารบัญ (INDEX)** | **DN 33 + DN 34** | มาติกาเชิงตัวเลข 1–10 = สารบัญที่คัมภีร์สร้างเอง |
| **เชิงอำนาจ (AUTHORITY)** | **DN 16** | จตุมหาปเทส = เกณฑ์วินิจฉัยพุทธวจนะ |
| **เชิงวิเคราะห์ (WHICH)** | MN 117 | มรรค 8→10, โลกิย/โลกุตตร |
| **เชิงหมวดธรรม (WHO)** | DN 22 | นิวรณ์/ขันธ์/อายตนะ/โพชฌงค์ |
| **เชิงวิธี (HOW)** | MN 118 | อานาปานสติ 16 ขั้น |
| **เชิงหลักสูตร (CURRICULUM)** | **MN 62** | กรรมฐานครบวงจร (ธาตุ→อานาปาน→พรหมวิหาร→อสุภ→อนิจฉ) |
| **เชิงแผนที่สัมมาทิฏฐิ** | **MN 9** | สัมมาทิฏฐิ = อกุศล/กุศล→อาหาร→สัจจะ→ปฏิจจสมุปบาท→อาสวะ |

## 7. บทสรุป: "สารบัญ" ที่สมบูรณ์ที่สุดของพระไตรปิฎก

ผลรวมจาก root ทั้ง 9 ตัวชี้ว่า แผนที่พระไตรปิฎกที่สมบูรณ์ที่สุดมี **4 แกน**:

1. **SN 56.11** (WHAT) + **DN 2** (PATH) = แกนหลัก 2 (ทำแล้ว)
2. **DN 33 + DN 34** (INDEX) = **สารบัญเชิงตัวเลขที่คัมภีร์สร้างเอง** — เป็น "ดัชนี" ตามจำนวน 1–10
3. **DN 16** (AUTHORITY) = **เกณฑ์วินิจฉัยความเป็นพุทธวจนะ** (จตุมหาปเทส) — เป็น "root เชิงอำนาจ" ที่รองรับพระไตรปิฎกทั้งปวง
4. **MN 62** (CURRICULUM) + **MN 9** (สัมมาทิฏฐิ) = หลักสูตรปฏิบัติ/แผนที่ญาณ

**คำตอบของคำถาม "มี root อะไรอีกบ้าง":** ตัวพระไตรปิฎกมี **"root โดยธรรมชาติ"** ที่เราควรนับเป็น root จริง 4 ตัวเพิ่มเติม — โดยสำคัญที่สุดคือ **DN 33/34 (สารบัญเชิงตัวเลข)** และ **DN 16 (หลักวินิจฉัยพุทธวจนะ)** เพราะเป็นโครงสร้างที่ตัวคัมภีร์**สร้างไว้เอง**เพื่อจัดระเบียบและตรวจสอบธรรมะ ไม่ใช่การที่เราตีความย้อนหลัง
