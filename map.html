แผนที่พระธรรม (Dhamma Map)

ค้นหาและนำทางพระไตรปิฎกด้วยศัพท์บาลี — index เชิงความหมายที่เชื่อม พระสูตร ↔ ศัพท์ ↔ หมายเลขท่อน (segment)

Pāli index · ไม่พึ่ง index ภาษาอังกฤษ · ตัวบทบาลีโรมันเท่านั้น

เครื่องมือนี้ใช้ทำอะไรได้

1. ระบบค้นหา

ค้นศัพท์/พระสูตร/ท่อน ได้ทันที พร้อมลิงก์ลึกถึงข้อความต้นฉบับ

2. Embedded index เชิงความหมาย

index ด้วยศัพท์บาลี + คำแปลไทย (ไม่ใช้ index ภาษาอังกฤษที่คลาดเคลื่อน)

3. แผนที่พระธรรม

เห็นว่าแต่ละศัพท์เชื่อมพระสูตร/ปิฎกใด ด้วยขอบเชื่อมที่มีหลักฐาน

4. แปลตาม root

ไล่แปลจาก "ใจกลาง" (root) แผ่ออก — สแกนหาการแปลที่ผิดได้เร็ว

ศัพท์ที่พบ
พระสูตร / ท่อนข้อความ
