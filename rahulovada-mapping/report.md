# มหาราหุโลวาทสูตร (MN 62) เป็นโครงสร้าง/สารบัญของพระไตรปิฎกได้หรือไม่
### รายงานวิจัย — root ชนิด "หลักสูตรกรรมฐานครบวงจร" วิเคราะห์จากตัวบทบาลีโรมันเท่านั้น

> **ข้อกำหนดวิธีวิจัย:** หลักฐานทุกชิ้นจากตัวบท**ภาษาบาลีโรมัน**โดยตรง (tripitaka-mcp local + online, SuttaCentral `bilara-data` CC0) ไม่ได้พึ่งการแปลภาษาอังกฤษ/ภาษาใดในการวิเคราะห์ ตัวเลขทุกตัวสืบย้อนได้จาก `survey_corpus` (exhaustive `complete:true`)

## บทคัดย่อ (Abstract)

**คำตอบ: ได้ — และเป็น root ชนิด "หลักสูตรกรรมฐานครบวงจร" (meditation curriculum) ซึ่งต่างจาก SN 56.11 (เชิงเนื้อหา) และ DN 2 (เชิงลำดับ)**

มหาราหุโลวาทสูตร ([MN 62](https://tripitaka-mcp.com/read/mn62)) ใช้เป็นราก/สารบัญได้ โดยเป็นพระสูตรที่**มัดรวมกรรมฐานหลักทั้งหมดไว้เป็น "หลักสูตรเดียว"** ที่พระพุทธเจ้าประทานแก่พระราหุล:

```
5 ธาตุ (ปฐวี/อาโป/เตโช/วาโย/อากาส)  → เห็นอนัตตา   [mn62:8-12]
ธาตุอุปมา (ปฐวีสม…อากาสสม)          → เจริญอุเบกขา  [mn62:13-17]
พรหมวิหาร 4 (เมตตา/กรุณา/มุทิตา/อุเบกขา) → ละอกุศล   [mn62:18-21]
อสุภ                                → ละราคะ       [mn62:22]
อนิจจสัญญา                          → ละอัสมิมานะ  [mn62:23]
อานาปานสติ 16 ขั้น                    → กรรมฐานหลัก  [mn62:24-30]
```

**ข้อค้นพบชี้ขาด:** หมวดอานาปานสติของ MN 62 ([mn62:25–29](https://tripitaka-mcp.com/read/mn62#mn62:25.1)) **เหมือนกับอานาปานสติสูตร MN 118 ทั้งชุดคำต่อคำ** (16 ขั้น 4 จตุรกะ) และหมวดปฐวีธาตุ ([mn62:8.2](https://tripitaka-mcp.com/read/mn62#mn62:8.2)) บรรจุ **กาย 31 ส่วน** เช่นเดียวกับมหาสติปัฏฐานสูตร DN 22 — จึงเป็น "จุดรวม" ที่เชื่อม root เชิงเนื้อหา/ลำดับ/วิธี เข้าด้วยกัน

---

## 1. บทนำและสมมติฐาน

**คำถาม:** MN 62 ใช้เป็น root ได้หรือไม่ และเป็น root ชนิดใด? กรรมฐานชุด MN 62 ครอบคลุมกรรมฐานหลักของพระไตรปิฎกอย่างไร (เชื่อมกับ DN 22 และ MN 118 อย่างไร)?

**สมมติฐาน H1 (ทดสอบแล้ว สนับสนุน):** MN 62 เป็น root ชนิด **"หลักสูตร"** — มัดรวมกรรมฐานหลัก (ธาตุ/พรหมวิหาร/อสุภ/อนิจจสัญญา/อานาปาน) ไว้เป็นชุดเดียว ที่ตัวพระสูตรสอนตามลำดับ

**สมมติฐาน H2 (ทดสอบแล้ว สนับสนุน):** กรรมฐานชุด MN 62 เชื่อมกับ DN 22 (ธาตุมนสิการ + ปฏิกูลมนสิการ) และ MN 118 (อานาปานสติ 16 ขั้น) ผ่านตัวบทที่เหมือนกันคำต่อคำ

### 3.3 ข้อค้นพบชี้ขาด 3 ประการ

**1) MN 62 = "หลักสูตร" ที่มัดรวมกรรมฐานหลักไว้ชุดเดียว** — ธาตุ 5 → ธาตุอุปมา → พรหมวิหาร 4 → อสุภ → อนิจจสัญญา → อานาปานสติ 16 ขั้น โดยแต่ละข้อมี **"ผล" กำกับชัดเจน** (เช่น เมตตา → ละพยาบาท [mn62:18.2](https://tripitaka-mcp.com/read/mn62#mn62:18.2); อสุภ → ละราคะ [mn62:22.2](https://tripitaka-mcp.com/read/mn62#mn62:22.2); อนิจจสัญญา → ละอัสมิมานะ [mn62:23.2](https://tripitaka-mcp.com/read/mn62#mn62:23.2)) — นี่คือ "โครงสร้างหลักสูตร" ที่เห็นทั้ง "วิธี" และ "ผล"

**2) หมวดอานาปานสติของ MN 62 = MN 118 ทั้งชุดคำต่อคำ** — [mn62:25–29](https://tripitaka-mcp.com/read/mn62#mn62:25.1) แสดง 16 ขั้น 4 จตุรกะ (ทีฆ/รสฺส → สพฺพกาย → ปสฺสมฺภยํ กายสงฺขารํ → ปีติ/สุข → … → อนิจฺจานุปสฺสี) **ตรงกับ** [mn118:18–21](https://tripitaka-mcp.com/read/mn118#mn118:18.1) และปัจฉิมบท *"จริมกา อสฺสาสา เตปิ วิทิตาว นิรุชฺฌนฺติ"* ([mn62:30.2](https://tripitaka-mcp.com/read/mn62#mn62:30.2)) สะท้อนปลายทางเดียวกัน

**3) หมวดปฐวีธาตุบรรจุ "กาย 31 ส่วน" เหมือน DN 22** — *"เกสา โลมา นขา ทนฺตา ตโจ … กรีสํ"* ([mn62:8.2](https://tripitaka-mcp.com/read/mn62#mn62:8.2)) = รายการเดียวกับปฏิกูลมนสิการของ [DN 22](https://tripitaka-mcp.com/read/dn22) (หมวดกายานุปัสสนา) → MN 62 เชื่อม DN 22 ทาง "ธาตุ/กาย" และเชื่อม MN 118 ทาง "อานาปาน" พร้อมกัน

### 3.4 MN 62 ในฐานะ "root เชิงหลักสูตร" — เทียบกับ root ชนิดอื่น

| root | ชนิด | แก่น |
|---|---|---|
| SN 56.11 | เชิงเนื้อหา (WHAT) | อริยสัจ 4 = ธรรมะทั้งหมด |
| DN 2 | เชิงลำดับ (PATH) | ไตรสิกขา = 3 ปิฎกเป็น 3 ขั้น |
| DN 33/34 | เชิงสารบัญ (INDEX) | มาติกา 1–10 |
| DN 16 | เชิงอำนาจ (AUTHORITY) | จตุมหาปเทส |
| **MN 62** | **เชิงหลักสูตร (CURRICULUM)** | **ชุดกรรมฐานครบ + ผลของแต่ละข้อ** |
| DN 22 | เชิงหมวดธรรม (WHO) | สติปัฏฐาน 4 |
| MN 118 | เชิงวิธี (HOW) | อานาปานสติ 16 ขั้น |

**จุดต่างสำคัญ:** MN 62 **ไม่ซ้ำกับ SN 56.11 (เนื้อหา) หรือ DN 2 (ลำดับ)** แต่เป็น root ที่ตอบคำถาม **"ต้องฝึกอะไรบ้าง และฝึกแล้วได้ผลอะไร"** — โดยมัดกรรมฐานที่กระจายอยู่ตาม root อื่น (DN 22, MN 118) มาอยู่ในพระสูตรเดียว

## 5. อภิปราย (Discussion)

### 5.1 MN 62 ครอบคลุมกรรมฐานหลักของพระไตรปิฎกอย่างไร

| กรรมฐานใน MN 62 | ละอกุศล | เชื่อม root อื่น |
|---|---|---|
| ธาตุ 5 (มหาภูต) | (เห็นอนัตตา) | DN 22 ธาตุมนสิการ; อภิธรรม มหาภูต 659 |
| ธาตุอุปมา | (เจริญอุเบกขา) | — |
| เมตตา/กรุณา/มุทิตา/อุเบกขา | พยาบาท/วิเหสา/อรติ/ปฏิฆะ | งานวิจัย metta-research / karuna-research |
| อสุภ | ราคะ | DN 22 ปฏิกูลมนสิการ |
| อนิจจสัญญา | อัสมิมานะ | MN 118 จตุรกะ 4 (อนิจฺจานุปสฺสี) |
| อานาปานสติ 16 ขั้น | (กรรมฐานหลัก) | MN 118 ทั้งชุด; สติปัฏฐาน 4 (SN 45.8:9.2) |

→ MN 62 ทำหน้าที่เป็น **"จุดรวม" (hub)** ที่เชื่อม root เชิงเนื้อหา/ลำดับ/หมวด/วิธี เข้าด้วยกันผ่าน "ชุดกรรมฐาน" ของมัน

### 5.2 โปรไฟล์เชิงปิฎก: อภิธรรมหนัก (ผ่านมหาภูต), วินัยอ่อน

ศัพท์ลายเซ็นของ MN 62 (มหาภูต 659, อุเบกขา 788, ปฐวีธาตุ 49 ในอภิธรรม) หนักไปทาง**อภิธรรม** — เพราะ "ธาตุ" เป็นวัตถุวิเคราะห์ของอภิธรรม (ธาตุกถา/วิภังค์) แต่**วินัยเกือบเป็นศูนย์** (มหาภูต 0, ปฐวีธาตุ 0) — โปรไฟล์คล้าย DN 22 / MN 118 (อภิธรรม+สุตตันตะ, วินัยอ่อน) ต่างจาก SN 56.11 / DN 2 ที่เชื่อมวินัยได้

### 5.3 คำตอบ: MN 62 ใช้เป็น root ได้หรือไม่

**ได้** — โดยเป็น root ชนิด **"หลักสูตรกรรมฐาน"** ที่: (1) มัดกรรมฐานหลักครบชุด (ธาตุ/พรหมวิหาร/อสุภ/อนิจจสัญญา/อานาปาน), (2) กำกับ "ผล" ของแต่ละข้อ (ละอกุศลอะไร), (3) บรรจุอานาปานสติ 16 ขั้น (= MN 118) และกาย 31 ส่วน (= DN 22) ไว้ในตัว — จึงเหมาะเป็น **"สารบัญเชิงปฏิบัติ"** ที่ตอบ "ฝึกอะไร → ได้ผลอะไร" ไม่ใช่ "ธรรมะคืออะไร" (SN 56.11) หรือ "ปฏิบัติเป็นลำดับอย่างไร" (DN 2)

## 6. ข้อจำกัดและการตรวจสอบตนเอง

1. **ศัพท์กว้างนับเกิน (over-match):** `upekkhā` (1539) รวม "อุเบกขาเวทนา" (เวทนากลาง) และ "อุเบกขาสัมโพชฌงค์" ซึ่งไม่ใช่ "อุเบกขาพรหมวิหาร" โดยตรง → ตัวเลขเป็นขอบเขตบน; `mahābhūta` (741) หนักอภิธรรมเพราะอภิธรรมวิเคราะห์ธาตุ 4 ทุกแห่ง
2. **การเชื่อมวินัยอ่อน** (มหาภูต 0, ปฐวีธาตุ 0 ในวินัย) — MN 62 เป็นกรรมฐานเชิงจิต ไม่ใช่วินิจฉัยข้อวัตร จึงไม่เชื่อมวินัยด้วยศัพท์
3. **"พรหมวิหาร" (brahmavihāra) ปรากฏเพียง 4 ข้อความ** — เป็นศัพท์เทคนิคที่หายากในพระไตรปิฎก แม้มโนทัศน์ เมตตา/กรุณา/มุทิตา/อุเบกขา จะกว้างขวาง (ดูรายงาน metta-research/ karuna-research/ แยก)

## 7. สรุป

**มหาราหุโลวาทสูตรใช้เป็นราก/สารบัญได้** โดยเป็น root ชนิด **"หลักสูตรกรรมฐานครบวงจร"** ที่มัดรวม ธาตุ 5 → ธาตุอุปมา → พรหมวิหาร 4 → อสุภ → อนิจจสัญญา → อานาปานสติ 16 ขั้น ไว้ชุดเดียว พร้อม "ผล" ของแต่ละข้อ — และเป็น **"จุดรวม"** ที่เชื่อม DN 22 (กาย 31/ธาตุ), MN 118 (อานาปาน 16 ขั้น), และงานเมตตา/กรุณา (พรหมวิหาร) เข้าด้วยกัน ผ่านตัวบทที่เหมือนกันคำต่อคำ
